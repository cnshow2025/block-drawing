# 方塊填色 Block Drawing

把繽紛方塊拖進畫框的填充拼圖遊戲。純 HTML + CSS + JavaScript，沒有建置流程、沒有外部依賴，
用瀏覽器直接開 `index.html` 就能玩，手機與桌機都支援。

## 玩法

- **拖曳**方塊盤裡的方塊放進畫框，方塊會自動吸附到格線上。
- 放下前會出現**落點預覽**：綠色代表可以放，紅色代表卡到東西。
- 點一下方塊可以**選取**，再按「旋轉」「翻轉」調整方向；拖曳途中也能直接按。
- 放錯了可以把方塊**從畫框裡拖回來**，或按「復原」。
- 鍵盤快捷鍵：<kbd>R</kbd> 旋轉、<kbd>F</kbd> 翻轉、<kbd>Ctrl</kbd>+<kbd>Z</kbd> 復原、<kbd>Esc</kbd> 取消。

### 兩種關卡模式

| 模式 | 過關條件 | 星等怎麼算 |
| --- | --- | --- |
| **精準拼合** | 用完所有方塊、畫框 100% 填滿 | 不用提示三顆星，用一次兩顆星，用更多一顆星 |
| **填滿計分** | 填滿率跨過一星門檻 | 依填滿率跨過三道門檻，使用提示會扣減 |

## 五個世界，三十道關卡

| 世界 | 主題 | 方塊 | 畫框 |
| --- | --- | --- | --- |
| 1 幾何樂園 | 入門 | 骨牌、直三、角三、正方形 | 乾淨矩形 |
| 2 方塊工廠 | 四格 | tetromino 七件全套 | 矩形、中央天井 |
| 3 洞穴迷宮 | 四＋五格 | tetromino ＋ pentomino | 孔洞、缺口、石柱 |
| 4 碎片星河 | 五格 | pentomino 十二件 | 十字、菱形、階梯、環形 |
| 5 繽紛花園 | 五＋六格 | pentomino ＋ 不規則六格 | 花朵、星星、愛心、貓咪、蝴蝶、皇冠 |

進度（星數與最佳填滿率）存在瀏覽器的 `localStorage`，關卡依序解鎖。

## 關卡是怎麼出的

與其「出題之後再想辦法解」，這個遊戲反過來做：**先把空畫框完整切成碎片**。

1. 拿關卡的畫框輪廓，用回溯法把可填區完整切成該世界形狀池裡的形狀。
2. 切出來的碎片就是玩家手上的方塊盤——所以精準拼合模式**必定有解**。
3. 切割由關卡表裡的固定種子驅動，同一關每次進入都是同一題。
4. 計分模式再從這組碎片抽掉幾塊、補進幾塊隨機形狀，讓完美填滿幾乎不可能，改以填滿率論高下。

回溯時有兩道剪枝讓它跑得很快：每塊連通空白區的格數必須 ≥ 最小形狀，而且必須能由形狀池的尺寸組合出來。
三十關全部生成完不到一秒。

## 專案結構

```
index.html              單一入口
css/style.css           主題色、版面、動畫
js/shapes.js            形狀資料庫與旋轉／鏡像變換
js/generator.js         種子亂數、畫框解析、反向切割、填滿率估算
js/levels.js            五個世界三十關的資料
js/board.js             棋盤模型、放置驗證、填滿率、星等、提示
js/storage.js           localStorage 進度存檔
js/audio.js             WebAudio 即時合成音效（不需音檔）
js/render.js            把遊戲狀態畫成 DOM
js/input.js             Pointer Events 拖曳、旋轉、翻轉
js/game.js              主流程：畫面切換、關卡選單、結算
tools/validate-levels.js  關卡驗證腳本
```

## 開發

沒有安裝步驟。要本機跑起來：

```bash
python3 -m http.server 8000     # 或任何靜態伺服器
# 開 http://localhost:8000
```

改了關卡資料之後，跑驗證腳本確認每一關都還切得出來：

```bash
node tools/validate-levels.js
```

它會列出每關的格數、塊數與實際用到的種子；計分關卡還會用「最佳貼合」啟發式估算可達的最高填滿率，
用來校準星等門檻。
